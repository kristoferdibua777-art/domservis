# Сайт «СВИБ Дом Сервис»

Одностраничный сайт компании по брендбуку v1.0 (`svib-brand/`, ветка `claude/svib-brand-identity-system-efbf2a`).
Чистые HTML и CSS без сборки; один небольшой скрипт показывает, открыты ли мы сейчас. Папку можно выложить на любой
статический хостинг; сейчас её отдаёт Caddy сервера CRM.

## Что на странице

1. Шапка: логотип, разделы, телефон, кнопка «Оставить заявку».
2. Первый экран: слоган, список направлений, кнопки заявки и звонка, строка «Сейчас открыто / закрыто»; справа
   фирменная композиция (синяя и красная полосы под 30°, синяя плашка с белым знаком), как на баннере брендбука.
3. Услуги: восемь плиток иконок, как в разделе 13 брендбука, и строка «Не нашли свою задачу?». Каждая плитка —
   ссылка на форму заявки с этой услугой (см. ниже).
4. Как мы работаем: четыре шага от заявки до оплаты.
5. Ценности бренда: надёжность, профессионализм, забота о клиенте, качество, оперативность.
6. Синий блок с призывом, контакты с часами работы и строкой «Сейчас открыто / закрыто», тёмно-синий подвал
   с белым логотипом и ссылкой на политику конфиденциальности.
7. На телефоне внизу закреплена панель «Позвонить / Оставить заявку».
8. Отдельная страница `privacy.html` — политика конфиденциальности.

Все кнопки заявки ведут на действующую двухшаговую форму для клиентов
(`public/assets/form/dom-servis-client-request.html`): заявка с фото сразу попадает на доску диспетчера.

## Плитки услуг и форма

Плитки повторяют раздел 13 брендбука «Иконки услуг»: светло-серая плашка с иконкой и подпись под ней. Вся плитка —
одна ссылка. При наведении (и при фокусе с клавиатуры, и при касании) плашка становится фирменно-синей, синие линии
иконки — белыми, а красная «рабочая деталь» остаётся красной, как у логотипа на синем фоне. Иконки встроены в
разметку (`<svg>` с группами `…-base` и `…-accent` из файлов брендбука), чтобы CSS мог перекрасить линии.

Список услуг совпадает с категориями формы (`CATS` в `dom-servis-client-request.html`). Ссылка плитки добавляет
к адресу формы `&service=<id>`, а для услуг внутри «Другое по дому» ещё `&issue=<вариант>`, записанный ровно так,
как его показывает форма. Форма открывается сразу на втором шаге с выбранной услугой.

| Плитка | `service` | `issue` |
|---|---|---|
| Газовые котлы и отопление | `boiler` | — |
| Бойлеры и колонки | `heater` | — |
| Сантехника | `plumb` | — |
| Электрика | `electric` | — |
| Бытовая техника | `appliance` | — |
| Окна и двери | `other` | — |
| Сборка мебели | `other` | Повесить или собрать |
| Решение бытовых проблем | `other` | Мелкий ремонт |
| Не нашли свою задачу? | `other` | — |

Если в форме переименуют вариант или категорию, поправьте и сайт: неизвестные значения форма молча пропускает, и
клиент попадёт на первый шаг или увидит услугу без отмеченного варианта. Выбор по ссылке появился в форме вместе с
этим разделом; до выкладки новой версии формы такие ссылки открывают её на первом шаге.

## «Сейчас открыто / закрыто»

`assets/js/open-status.js` считает по времени Калининграда (а не по часам посетителя) и пишет, например,
«Сейчас открыто, до 18:00» или «Сейчас закрыто. Перезвоним в понедельник в 10:00, заявку можно оставить уже сейчас».
Часы заданы в начале файла; праздники и разовые выходные скрипт не знает. Без JavaScript строка просто не видна.

## Контакты на странице

Телефон +7 (911) 485-66-32, выезд по Калининграду и Гурьевску. Часы работы: пн–пт 10:00–18:00, сб 10:00–15:00,

Почты на сайте нет. При смене часов поправьте три места: блок контактов в `index.html`, JSON-LD там же и `HOURS`
в `assets/js/open-status.js`.

## Ссылка на форму и домен

Все кнопки заявки ведут на форму одного источника заявок DomServis:
`https://crm.svibservis.ru/assets/form/dom-servis-client-request.html?request_source_token=…`. Параметр `v` в ссылку
не добавлен: он меняется с каждым выпуском, а форма его не читает. Если источник сменится или его ключ перевыпустят,
замените ключ во всех ссылках одной командой (старый и новый ключ — из карточки источника в админке):

```bash
sed -i 's/request_source_token=СТАРЫЙ_КЛЮЧ/request_source_token=НОВЫЙ_КЛЮЧ/g' svib-site/index.html
```

Домен сайта — `svibservis.ru`: он и `www.svibservis.ru` в DNS указывают на сервер CRM (как `crm.svibservis.ru`).
На него ссылаются canonical, Open Graph, `robots.txt` и `sitemap.xml`.

Тексты услуг, шагов и ценностей — черновик (услуги взяты из листовки брендбука). Перед публикацией согласуйте
формулировки, особенно обещания вроде «постараемся приехать в тот же день».

## Политика конфиденциальности

`privacy.html` описывает, какие данные собирает форма заявки (имя, телефон, адрес, описание, фото, технический
идентификатор браузера), зачем, на каком основании и как их удалить. Оператор — ИП, реквизиты и почта взяты из
выписки ЕГРИП от 13.10.2025; сервер — у хостинг-провайдера SpaceWeb в России (по данным RIPE для адреса сервера).
Текст лучше показать юристу.
Когда страница выложена, её адрес `https://svibservis.ru/privacy.html` указывают в поле «Политика конфиденциальности»
источника заявок: тогда в согласии формы появится ссылка на неё.

## Выкладка на сервер CRM

Сайт отдаёт тот же Caddy, что обслуживает `crm.svibservis.ru`: папка `/opt/svib-home-service/svib-site` смонтирована
в контейнер только для чтения, в Caddyfile — блоки `svibservis.ru` и `www.svibservis.ru` (перенаправление).

Обновить сайт: собрать архив папки из `main` (`git archive --format=tar.gz -o svib-site.tgz origin/main svib-site`),
загрузить на сервер, сверить sha256 и распаковать поверх `/opt/svib-home-service/svib-site`. Caddy перезапускать
не нужно. Саму папку не подменять (`mv`): контейнер продолжит видеть старую.

## Просмотр на своём компьютере

```bash
npx -y http-server@14.1.1 svib-site -p 8090 -c-1
```

Затем откройте <http://localhost:8090>.

| Путь | Что это |
|---|---|
| `index.html` | Главная страница |
| `privacy.html` | Политика конфиденциальности |
| `assets/css/site.css` | Стили; цвета и шрифт — из `brand-tokens.json` брендбука |

| `assets/logo/` | Логотипы SVG из брендбука (шапка, подвал, знак на первом экране), иконки PWA, картинка для соцсетей `og-image.png` (1200 × 630) |
| `assets/icons/color/` | Иконки услуг, ценностей и контактов из брендбука (цветные, для светлого фона); `water-heater.svg` — из формы заявки, нарисована по правилам брендбука |

| `robots.txt`, `sitemap.xml` | Для поисковиков |

Логотипы и иконки скопированы из `svib-brand/` без изменений. Если брендбук пересоберут, скопируйте файлы заново
с теми же именами.

## Правила бренда, которые соблюдает вёрстка

- Красный `#E30613` — только акценты: полосы, скат крыши в знаке, кнопки заявки, последний шаг. На синем фоне
  кнопки белые: красный на синем даёт контраст 1,4 : 1.
- Текст графитовый `#1C2533`, второстепенный — `#5B6678`; оба проходят WCAG AA на белом и светло-сером.
- Логотип в шапке — горизонтальный без слогана высотой 40 px (минимум 28 px), в подвале — со слоганом
  шириной 260 px (минимум 240 px).
- Анимация одна: полосы первого экрана выезжают при загрузке; при настройке «уменьшить движение» её нет.
